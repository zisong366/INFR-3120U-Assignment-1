# Zisong's Portfolio

# Project Description

This is my personal portfolio website created using HTML5 and CSS3. It includes four pages: Home, About ME, Projects, and Contact Me.

# Responsive Design
I used fluid design and CSS media queries with three separate stylesheets:
## Phone: 480px and below (phone.css)
## Tablet: 481px-960px (tablet.css)
## Desktop: Above 960px (full.css)

These dimensions allow the website to adapt to different screen widths. The phone layout uses vertical navigation and a full-width wrapper. The tablet layout uses a 90% wrapper, while the desktop layout uses a 960px wrapper.

I did not use Flexbox.

# Linear Gradients
I used two types of linear gradients:
## Directional linear gradient: Applied to the website header (#banner) using linear-gradient (to right, #013a40, #028090).
## Angle-based linear gradient: Applied to the footer using linear-gradient (135deg, #028090, #013a40).

These gradients are applied through the CSS stylesheets.

# Color Scheme
I selected a teal-based color palette using Adobe Color.

## Color harmony: Analogous
## Colors: #013a40, #028090, #22d7d7, #f4f9f9, #222222

I chose these colors to create a consistent appearance across the website. Dark teal provides contrast with white text, while lighter colors can be used for backgrounds and accents.
